# Ancestry Login Account Guide for Read the Docs

1. Create a new GitHub repository.
2. Upload `.readthedocs.yaml` and the `docs` folder to the repository root. Preserve filenames and folders.
3. Sign in at https://app.readthedocs.org/ and select **Import a Project**.
4. Select the GitHub repository, then create the Read the Docs project.
5. Wait for the build to complete and open **View Docs**.

To edit the article, change `docs/index.rst`, commit, and rebuild if automatic builds are not enabled.

This is an independent guide, not an official Ancestry website.
